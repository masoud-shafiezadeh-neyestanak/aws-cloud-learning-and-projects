# Project 01: Serverless Image Processing System

## Project Overview

The objective of this project is to design and implement a serverless image processing system using AWS services.

## Project Objectives

- Upload images to Amazon S3.
- Trigger AWS Lambda through S3 events.
- Resize images automatically.
- Store processed images in Amazon S3.
- Save image metadata in Amazon DynamoDB.

## AWS Services

- Amazon S3
- AWS Lambda
- Amazon DynamoDB
